# AeroKids Brand Rules

## Canonical logo
Use one canonical AeroKids logo everywhere.

Canonical web asset:
`https://aerokids.space/assets/logo/aerokids-logo-master.webp`

The logo is a **circle**. Do not treat a square screenshot background as part of the logo.

Never:
- redraw or regenerate the logo;
- change the drone/symbol shape;
- change the AERO / KIDS lettering;
- change proportions or spacing;
- stretch, skew, rotate, crop internal elements, or add new effects;
- create alternate logo variants with AI.

Allowed:
- scale proportionally;
- create size-optimized derivatives only from the canonical master without changing artwork, color, proportions or internal composition;
- mask/crop only the outside screenshot background to the circular boundary;
- place the unchanged logo on approved brand backgrounds.

## Brand palette
- Background: `#07100F`
- Secondary background: `#0D1918`
- Card/panel: `#10201F`
- Border: `#294442`
- Primary text: `#F2F1FB`
- Muted text: `#A7B7B5`
- Accent cyan/teal: `#69C7C8`
- Accent light: `#86DDDC`
- Dark text on cyan: `#071312`

## Visual direction
Dark graphite/black base, cyan/teal accents, off-white typography.
Avoid unrelated purple/yellow/blue accent systems except semantic CRM states where a status color is functionally required.

## Content direction
AeroKids is more than drones. Parent-facing wording should explain outcomes first:
- drones — control, structure, setup;
- electronics — sensors, light, motors, buttons;
- programming — giving devices commands;
- smart devices — Arduino and ESP32 as tools, not unexplained headline terms;
- own technical projects — from idea to working result.

Avoid making the room/interior the selling point. Prefer close-ups of equipment, hands-on work, diagrams, infographics, tools and results.
